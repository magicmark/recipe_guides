# New recipes

Create practical markdown meal guides for a busy parent shopping at Central Market in Texas. Unless the current request changes these defaults:

- Plan five weeknight dinners, each making **8 portions: 4 for dinner and 4 for lunch the next day**. Include all eight portions in ingredient and shopping quantities.
- Make every recipe fully dairy-free for a milk-protein allergy. Do not use butter, cheese, cream, whey, casein, ghee, or lactose-free dairy. Check relevant packaged ingredients; do not assume an unverified product is allergy-safe.
- Use only kosher animal species: chicken, turkey, beef, lamb, or fish with fins and scales. No pork, bacon, shellfish or other non-kosher animals. Kosher-certified meat is unnecessary. Mixing meat and milk would otherwise be acceptable, but dairy-free is mandatory.
- Keep flavors mild and approachable for children aged three and four. Put optional heat at the adult table.
- Limit total hands-on preparation and cooking to **20 minutes per recipe**; aim for **30 minutes elapsed**. Longer unattended cooking is acceptable, including stews. State realistic active and total times for the actual eight-portion batch.
- Assume salt, olive oil and basic pantry staples, but explicitly list other seasonings as cupboard checks.
- Deliberately overlap ingredients. Avoid buying specialty items for tiny one-off uses. When worthwhile, use them repeatedly that week or give a concrete next-week use before spoilage; state relevant storage. Use whole perishable packages where practical.
- Favor normal supermarket ingredients and useful shortcuts. Assume good Central Market availability without claiming live stock or naming unverified allergy-safe products.

## Guide format and workflow

Read existing guides and applicable repository instructions before adding files. Respect any current user changes over these defaults.

Save each guide at `week-of-YYYY-MM-DD/README.md`, using the Monday of the intended meal week. Include an explicit date heading and a `week-of-YYYY-MM-DD` frontmatter tag. For a Sunday shopping request planning the coming weekdays, use the following Monday and say so. Preserve existing weeks.

Include:
- A compact dinner table with active and elapsed times.
- A consolidated, checkable shopping list organized by grocery department, with practical package sizes and total quantities.
- Five complete recipes with quantities, usable numbered methods, equipment requirements when important, and a simple child-serving option.
- Four lunch portions reserved from each dinner, plus storage and reheating instructions.
- An ingredient-overlap/remaining-packages table with specific reuse or freezing plans.
- A shopping-day meat storage/thawing plan that does not leave raw poultry or ground meat refrigerated all week.

Reconcile shopping quantities against all recipes, including lunch portions, seasonings and optional ingredients. Scale equipment and methods alongside ingredients: do not double a skillet recipe and keep implausible time estimates. Favor larger-batch oven or pot methods if serial frying would exceed 20 minutes of active work. Clearly state any longer elapsed time.

Do not publish personal names or private health history in this public repository; describe the dietary requirement generically.

Use the authorized GitHub connection to save requested changes to `magicmark/recipe_guides`. Preserve unrelated files. If remote writes are blocked, finish the local deliverables and state that they have not been pushed; do not claim a local commit updated GitHub.
